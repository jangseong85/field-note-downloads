# 환자 기록 · 임상 탭 개선

2026-10-21, Android 1.0.3 (versionCode 4), 기존 배포 인증서로 업데이트 설치.

- 환자 선택과 측정 회차를 같은 인셋 세그먼트 스타일로 통일. 환자 뒷판은 인적사항·주증상·활력징후·병력 메모 전체를 감싼다.
- 이름과 성별을 한 줄에 배치하고 나이를 생년월일 입력면 안쪽에 표시한다. 입력값 글자는 16dp로 통일한다.
- 발생·측정 시각을 공통 날짜/요일/시간 서식으로 표시한다. 작은 화면과 큰 시스템 글꼴에서는 날짜와 시간을 세로 배치한다.
- 활력징후 측정 회차 추가·전환·삭제 및 환자별 자동 저장. 기존 단일 측정값은 첫 회차로 유지한다.
- 주증상·메모 입력창 오른쪽 아래 드래그 핸들로 높이를 조절한다. 스크린리더 크기 조절 동작도 제공한다.
- 선택 병력과 자유 메모를 구분한다. 기존 저장 메모는 삭제하지 않는다.
- 병력 메모 아래 녹취 시작/중지, 녹취 재생, 환부 사진 촬영 및 미리보기. 사용자가 동의 확인 후 녹취를 시작하며, 진행 중에는 환자 전환/삭제/초기화와 화면 이동을 제한한다. 백그라운드 전환 시 녹취를 중지·저장한다.
- 자료는 앱 내부 저장소에 보관한다. Android 자동 백업은 비활성화했다.

검증: TypeScript, lint, 공통 날짜·시간 검사, 측정 회차/기존 데이터 복원 검사, SALS 회귀 테스트 14개, APK 서명 및 16KB 정렬 검사 통과.
갤럭시 S23 울트라에 데이터 삭제 없이 업데이트 설치. 실기기에서 탭과 날짜/시간 영역을 육안 확인하고 이름 입력창의 다크 배경색을 보정했다. 마이크 녹음과 카메라 촬영은 사용자 환경을 수집하지 않기 위해 실제 수집 테스트를 수행하지 않았다.

설치 파일: `releases/FieldNote-1.0.3-ClinicalTabs.apk`.
