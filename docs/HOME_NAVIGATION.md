# 홈과 공통 설정 정리 — 2026-10-25

사용자 지시: 홈을 추가하고 설정 탭을 유지한다. 메모에서 크게 표시하던 소속은 홈에서 확인한다.
앞서 논의한 하단 바 약 20% 축소와 팝업 뒤 배경을 더 어둡게 하는 조정을 함께 적용한다.

- 첫 화면은 홈이며 하단 메뉴는 홈·메모·다수사상자·설정이다.
- 홈에서 소속·계급·성명을 확인하고 메모 및 설정으로 이동한다. 홈 이동은 환자를 추가하거나 초기화하지 않는다.
- 메모의 공통 헤더에서는 큰 소속명을 제거한다. 환자 입력과 녹취·촬영 중 이동 방지는 유지한다.
- 설정에는 기존 소속·대원 정보, 다크 모드, 휠 피커, 의학용어 설정을 모은다. 상단 빠른 옵션도 유지한다.
- 홈·설정은 별도 화면 모듈이며 기존 키와 저장 구조를 그대로 사용한다.
- 하단 바는 기본 약 58dp(기존 약 72dp), 아이콘 20dp, 글자 12dp다. 내부 터치 높이는 최소 50dp이며 글자 배율에 따라 확장한다.
- 4개 메뉴가 들어가도록 항목의 좌우 여백을 줄인다. 실제 측정된 높이로 선택 배경·원래 콘텐츠·활성 복사본을 정렬한다.
- 작은 팝업의 검정 배경 불투명도는 라이트 45%·다크 65%, 확인창과 하단 시트는 60%·75%다.
- iOS 시스템 알림의 배경 어두움은 운영체제가 제어한다. 앱이 그리는 팝업과 시트에 공통 배경값을 적용한다.

검증: 타입 검사·린트·전체 Node 테스트. 홈의 바로가기, 설정 콜백, 기존 데이터 저장 로직과 공통 세그먼트 제스처를 포함한다.
저장 키·환자 데이터 형식·버전·파일 경로는 변경하지 않는다. 커밋·설치·푸시는 별도 승인 대상이다.

## 2026-11-01 변경: 홈 제거, 설정 한 곳으로

사용자 지시: 홈 탭을 없애고 앱을 켜면 메모가 첫 화면이 되게 한다. 설정은 설정 탭 한 곳에만 둔다.

- 하단 메뉴는 메모·설정 두 칸이다. 다수사상자는 기능이 생기면 메모와 설정 사이에 추가한다.
- Android 뒤로가기는 설정 탭에서 메모로 돌아오고, 메모 탭에서는 기본 동작(앱 나가기)을 따른다.
- 상단 `…`는 메모 탭에서만 보이는 "메모 메뉴"다. 지금은 환자 기록 전체 초기화만 있고, 두 플랫폼 모두 버튼 아래 팝오버로 연다. 다크 모드·휠 피커·의학용어·소속 같은 설정 항목은 `…`에서 뺐다. 10/25의 "상단 빠른 옵션 유지" 결정은 이것으로 대체한다.
- 소속·계급·성명은 설정 맨 위에서 확인하고 고친다. SMS 발신 정보로는 그대로 쓴다.

## 2026-11-01 변경: 기록을 하단 5개 탭으로 나눔

사용자 지시: 한 화면 스크롤 대신 하단 네비를 환자·상태·약물·기록·설정 5개 탭으로 나누고, 문자 보내기는 상단 버튼으로 옮긴다. 위의 "메모·설정 두 칸" 결정은 이것으로 대체한다.

- **환자**: 신분증 촬영, 성명·생년월일·성별, 연락처
- **상태**: 주증상(Onset, 손글씨), 활력징후
- **약물**: 병력, 확인 항목, 병력 메모·손글씨, 약 봉투 분석(`docs/MEDICINE_BAG_ANALYSIS.md`)
- **기록**: 녹취, 사진
- **설정**: 기존과 같다.
- 환자 선택 줄(환자 추가·삭제 포함)은 네 개의 기록 탭 위에 공통으로 남는다. 탭을 바꿔도 선택한 환자는 그대로다.
- 앱을 켜면 환자 탭이 첫 화면이다. Android 뒤로가기는 다른 탭에서 환자 탭으로 오고, 환자 탭에서는 기본 동작(앱 나가기)을 따른다.
- 상단 오른쪽에는 `…` 메모 메뉴만 둔다(설정 탭에서는 숨김). 문자 보내기는 기록 탭의 첨부 아래 "문자로 보내기" 버튼이다(2026-11-01 사용자 지시로 상단 말풍선에서 옮김). 녹취·촬영 중에는 비활성화된다. 문자 시트(`SendPhotosSheet`)는 `PatientNoteScreen`에 있다.
- 녹취·촬영 중에는 탭 이동을 막는다(기존 규칙). 녹취 중에 기록 탭을 벗어나 녹취가 끊기는 일이 없다.
- 영상 촬영은 넣지 않는다(사용자 결정, 2026-11-01). 기록 탭은 사진과 녹취만 둔다.
- 저장 키·환자 데이터 형식은 바꾸지 않았다.
