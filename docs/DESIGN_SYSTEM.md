# EMS Log 디자인 기준

## 적용 범위

환자 기록, 활력징후, 과거력, 필기 도구, 카메라 안내, 홈, 설정 화면에 공통 적용한다. 기능과 기록 저장 정책은 변경하지 않는다.

## 타이포그래피

Pretendard를 유지한다. 글자 크기는 `src/design.ts`의 `TYPE` 역할 여섯 가지만 쓴다. 소스에 숫자로 된 글자 크기를 적지 않는다(테스트로 검사).

| 역할 | 크기 | 쓰는 곳 |
|---|---|---|
| display | 28 | 화면 제목(홈·설정), 홈 소속명, 활력징후 값 |
| numeric | 24 | 혈압 값, 휠 숫자 |
| section | 18 | 섹션·시트·대화상자 제목 |
| body | 16 | 입력, 목록 행, 본문 |
| sub | 14 | 라벨, 버튼, 칩, 보조 설명 |
| caption | 12 | 단위, 배지, 하단 메뉴 글자 |

굵기는 글꼴 파일로 직접 지정한다(`Pretendard-Regular/Medium/SemiBold/Bold`). 스타일 이름에 따라 크기를 몰래 바꾸던 `normalizeDesign`은 없앴다.

설정의 "글자 크기"(작게 0.9 / 보통 1.0 / 크게 1.15)는 모든 역할에 배율을 곱한다. 기기의 시스템 글자 크기도 그대로 함께 곱해진다. 스타일은 `makeStyles`로 만들고 컴포넌트 안에서 `useStyles()`로 받는다. 렌더 중에 쓰는 인라인 크기는 `useType()`을 쓴다. 휠 피커는 행 높이가 고정이라 배율을 적용하지 않는다.

## 형태와 간격

페이지 여백·영역 간격 16, 입력 및 주요 컨트롤 최소 높이 48, 컨트롤 모서리 12, 카드 모서리 16. 카드 그림자는 사용하지 않는다. 원형 카메라 버튼과 미디어 프레임은 목적에 맞는 기존 형태를 유지한다.

## 색상

`src/clinicalTheme.ts`가 기준이다. 라이트 모드는 따뜻한 회색 바탕(#F2F1EE)과 흰 표면, 회청색 강조(#4B6276)를 쓰고, 다크 모드는 거의 검정에 가까운 바탕(#101113)에 밝은 회청색 강조(#A6B9C9)를 쓴다. 119 레드(#C9232D)는 브랜드 표시에만 쓴다. 삭제·경고는 danger 색이며 의미를 텍스트와 함께 표시한다. 활력징후 칸의 파스텔 색은 구분용이며 이상 수치를 뜻하지 않는다. 새 코드는 색을 직접 적지 않고 테마 값을 쓴다.

## 접근성과 검증

Text/TextInput의 기본 글자 확대를 끄지 않는다. 컨트롤은 고정 높이 대신 최소 높이로 확장 가능하게 한다. 본 변경은 iOS Dynamic Type의 네이티브 의미별 스타일 전체 구현이 아니며, 실제 기기의 큰 글자 설정에서 날짜·과거력·필기 도구·하단 메뉴의 잘림을 추가 확인해야 한다. 작은 화면의 고정 폭 날짜 입력과 이미지 관련 영역은 별도 레이아웃 검증이 필요하다.
