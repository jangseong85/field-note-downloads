# 기록 자동 삭제와 현장 사용성 수정 — 2026-11-01

사용자 지시: 앱 전반 검토 결과 중 신분증 마스킹과 홈 보강은 제외하고, 기록은 24시간 후 자동 삭제하며, 나머지 수정은 알아서 진행한다.

## 24시간 자동 삭제 (저장 구조 변경)

- `PatientRecord`에 `createdAt`(epoch ms, 선택 필드)을 추가한다. AsyncStorage 키 `ems-log.current-patient.v1`과 workspace version 2는 유지한다.
- 마이그레이션: `createdAt`이 없는 기존 기록은 업데이트 후 첫 검사 시각을 등록 시각으로 기록하고 저장한다. 업데이트 직후 기존 기록이 바로 지워지지 않고 그때부터 24시간 동안 보관된다. 이전 버전 앱은 이 필드를 무시하므로 되돌려 설치해도 읽을 수 있다.
- 기기 시계가 등록 시각보다 과거로 돌아가 있으면 등록 시각을 현재로 맞춘다. 미래 시각이 기록되어 삭제되지 않는 일을 막기 위해서다.
- 등록 후 24시간이 지난 환자를 사진·녹취·필기·신분증 파일과 함께 삭제한다. 남는 환자가 없으면 빈 환자 하나를 만든다. 삭제된 환자가 선택 중이었으면 남은 환자 중 가장 최근 환자로 이동한다.
- 검사 시점: 복구 직후, 앱이 다시 활성화될 때, 실행 중 1시간마다. 신분증 촬영, 사진 촬영, 녹취, 필기 중에는 검사를 미루고 다음 검사 때 처리한다.
- 내용이 있던 기록을 삭제하면 건수를 알린다. 빈 기록은 조용히 교체한다.
- 설정 화면의 "기록 보관" 카드에 이 정책을 안내한다.
- 구현: `planPatientExpiry`(`src/patientWorkspace.ts`), `PatientStorage.expire`, App의 검사 루프. 테스트는 `scripts/test-patient-expiry.cjs`.

## 그 밖의 수정

- **권한**: `SYSTEM_ALERT_WINDOW`를 `app.json`의 `blockedPermissions`에 넣고, 로컬 `android/app/src/main/AndroidManifest.xml`(git 밖)에서는 `tools:node="remove"`로 뺀다. `INTERNET`은 ML Kit와 WebView 스플래시에 미치는 영향을 실기기로 확인하지 못해 유지한다.
- **녹취**: 동의 안내에 "화면이 꺼지거나 다른 앱으로 전환하면 그 시점까지 저장되고 멈춘다"를 추가한다. 동작은 바꾸지 않는다.
- **권한 거부 후 재요청 불가**: 카메라(신분증·사진)와 마이크 안내에 "설정 열기" 버튼을 추가한다.
- **신분증 OCR**: 인식한 성명·생년월일·성별은 빈 칸만 채운다. 이미 입력된 값과 다르면 비교를 보여 주고, "인식값으로 변경"을 눌렀을 때만 바꾼다.
- **필기**:
  - "모두 지우기"가 기존에 저장된 필기도 지운다. 새 획 없이 저장하면 필기를 삭제한다.
  - 그리는 중인 획은 프레임당 한 번만 화면에 반영하고, 끝난 획은 다시 그리지 않아 긴 획에서도 덜 버벅인다.
  - 저장 중이거나 저장에 실패한 상태에서는 지우기 버튼을 막는다.
  - 지우개 크기를 읽다가 실패해도 오류가 남지 않게 했다.
- **다수사상자 탭**: 기능이 생길 때까지 하단 메뉴에서 숨긴다. 메뉴는 홈·메모·설정 3개다.
- **화면 모드**: 설정에 "기기 화면 모드 따르기"를 추가한다. 다크 모드 스위치를 직접 바꾸면 이 설정은 꺼진다.
- **Android 뒤로가기**: 녹취·촬영 중에는 이동을 막고 안내한다. 홈이 아닌 탭에서는 홈으로 이동하고, 홈에서는 기본 동작(앱 나가기)을 따른다.

## 하지 않은 것

- 신분증 마스킹(사용자 제외)
- 홈 보강(사용자 제외)
- FLAG_SECURE(사용자 결정: 넣지 않음)
- 필기 지우개 색 문제: 지우개가 배경색을 덧칠하므로 테마를 바꾼 뒤 기존 필기를 지우면 자국이 남는다. 기존 PNG에 배경색이 함께 들어 있어서 고치려면 저장 형식을 바꿔야 한다.
- 상단 빠른 옵션과 설정 탭의 중복: 2026-10-25 지시("상단 빠른 옵션도 유지")에 따라 유지한다.
- FormState를 확장하는 기능 추가(AVPU/GCS, 처치 타임라인, 이송 병원, "측정 불가" 입력)와 앱 잠금은 별도 설계와 승인이 필요하다.
